# Greenlane Simulations

Two simple simulations supporting Green Lane planning.

## Simulations

### Simulation 1: Rack Capacity

Forecasts how many racks may need to be held at the Denton 3PL based on historical rack movement and current committed orders.

Link:

Simulation1_Rack_Capacity_Simple.html

### Simulation 2: Inventory Flow

Shows historical U.S. inventory flows and future committed inventory movement through the Green Lane network.

Link:

Greenlane_Inventory_Flow_Baseline.html
